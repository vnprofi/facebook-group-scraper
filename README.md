# FBSoft

Настольное приложение для сбора данных Facebook: участники групп и посты со страниц профилей. Работает в собственной изолированной сессии Facebook, данные сохраняются в CSV или Excel.

## Возможности

### Участники групп
- Сбор участников при ручной или автоматической прокрутке страницы
- Подсчёт собранных записей в реальном времени
- Экспорт в CSV и Excel

### Посты профиля
- Сбор постов со страницы пользователя при ручной или автоматической прокрутке
- Текст поста, дата, автор, ссылка на пост и ссылка на медиа
- Экспорт в CSV и Excel

### Общее
- Строгий нейтральный интерфейс: без градиентов, эмодзи и декоративных эффектов
- Выход из аккаунта очищает сессию Facebook (`persist:fb`)
- Одна кнопка сброса данных для активной вкладки

## Как это работает

Приложение открывает `facebook.com` в `<webview>` с отдельной сессией. При запуске сбора в страницу внедряется скрипт `src/injected.js`, который:

1. Перехватывает ответы `POST /api/graphql/` (XHR и fetch).
2. Из ответов с `new_members` / `new_forum_members` / `search_results` забирает участников группы.
3. Из ответов с узлами `__typename: "Story"` (лента профиля, `timeline_list_feed_units`) забирает посты.
4. Прокручивает страницу до тех пор, пока подгружается новый контент.

Никакие запросы не формируются вручную: используются только ответы, которые Facebook отдаёт сам при прокрутке. Поэтому doc_id и токены не «зашиты» в код и не ломаются при обновлениях Facebook.

## Требования

- Windows 10/11 (x64) или macOS (Intel / Apple Silicon)
- Аккаунт Facebook, в который выполнен вход в окне приложения

## Запуск из исходников

```bash
npm install

```

## Использование

### Участники группы

1. Вставьте ссылку на группу и нажмите «Открыть». Если указана ссылка вида `facebook.com/groups/<id>`, приложение сразу откроет вкладку участников.
2. Если открылась лента группы, перейдите во вкладку «Участники».
3. Нажмите «Автоскролл» или «Ручной скролл».
4. Дождитесь окончания сбора, затем нажмите «Экспорт CSV» или «Экспорт Excel».

### Посты профиля

1. Вкладка «Посты профиля».
2. Вставьте ссылку на профиль и нажмите «Открыть».
3. Нажмите «Автоскролл» или «Ручной скролл».
4. Экспортируйте данные.

Сбор постов доступен только на странице профиля: на странице группы приложение покажет подсказку.

## Формат данных

### Участники

`Profile Id`, `Full Name`, `ProfileLink`, `Bio`, `Image Src`, `Groupe Id`, `Group Joining Text`, `Profile Type`

### Посты

`ID поста`, `Дата`, `Автор`, `Ссылка на автора`, `Текст поста`, `Ссылка на пост`, `Медиа`

CSV сохраняется с разделителем `;` и BOM — так Excel корректно открывает кириллицу. Excel-файл формируется через библиотеку `xlsx`, ширина колонок подстраивается автоматически.

## Сборка

```bash
npm run build-win   # NSIS-установщик для Windows x64
npm run build-mac   # DMG + ZIP для macOS x64 и arm64
npm run build-all   # обе платформы
```

Готовые файлы складываются в `dist/`.

### GitHub Actions

Workflow `.github/workflows/build.yml` собирает Windows и macOS на каждом push в `main`, а также по тегам `v*` и вручную (`workflow_dispatch`). Скачать артефакты можно на вкладке Actions.

macOS-сборка не подписана сертификатом Apple. При первом запуске система может показать предупреждение: откройте приложение через «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть» или правой кнопкой мыши → «Открыть».

## Ограничения

- Facebook может менять структуру ответов GraphQL. Парсер ищет данные по именам полей (`new_members`, `timeline_list_feed_units`, `__typename: Story`) и переживает большинство изменений, но не все.
- Уже загруженные до запуска сбора записи могут не попасть в выборку: перехват включается в момент старта. При ручной прокрутке вниз подгружаются новые данные.
- При переходе на другую страницу внутри Facebook список очищается — это ограничение самой веб-страницы, данные нужно экспортировать до перехода.
- Приватные профили и закрытые группы отдают только то, что доступно вашему аккаунту.

## Структура проекта

```
src/
  main.js       — главный процесс: окно, диалоги сохранения, сессия
  preload.js    — мост renderer ↔ main
  index.html    — интерфейс приложения
  injected.js   — сборщик данных внутри страницы Facebook
.github/
  workflows/build.yml — сборка Windows и macOS
```
